# Edytor Foto 1.10

Edytor zdjęć w przeglądarce: wywoływanie RAW i JPG (silnik zgodny z Lightroomem), kadr, maski, presety, ziarno, korekcja obiektywów Canon RF i napisy na Instagram.

**Otwórz:** https://sobolewskicreator.github.io/Edytor-foto/

- Działa na iPadzie, iPhonie, Macu, Windowsie i Androidzie – bez instalacji, bez konta.
- iPad/iPhone: otwórz link w Safari → Udostępnij → „Do ekranu początkowego”. Edytor dostaje własną ikonę i po pierwszym otwarciu działa też offline.
- Zdjęcia i prace zostają tylko na Twoim urządzeniu (nic nie jest wysyłane na serwer).
